## DeepThink 1.0.3

A stability and correctness release. Several of these fixes address data-loss and
data-integrity bugs — upgrading is strongly recommended.

### Critical fixes

- **Shell config could be overwritten.** Adding `~/.local/bin` to `PATH` read your shell
  rc file and, if that read failed for any reason, treated it as empty and wrote it back
  containing only DeepThink's export line — destroying the rest of `.zshrc` /
  `.bash_profile` / `.bashrc`. The installer now skips any rc file it cannot read.
- **Agent config could be overwritten.** `deepthink install` parsed `~/.claude/settings.json`
  and `~/.cursor/mcp.json` with a fallback that turned malformed JSON into an empty object,
  then wrote the result back — so one stray comma in your config replaced the whole file
  with just DeepThink's keys. Install now fails loudly and leaves the file untouched.
- **Semantic search index was being erased.** Incremental knowledge reloads pruned the
  vector index against only the *changed* entries, deleting the embeddings of every
  unchanged entry on nearly every scan. Search results were silently incomplete.
- **The app could hang indefinitely.** Subprocess calls waited for exit before draining
  stdout, so any response larger than the 64KB pipe buffer deadlocked forever and left the
  UI stuck "processing". Claude responses routinely exceed that. Fixed across the Claude
  CLI, MCP, DeepThink CLI, and script-execution paths, all now with timeouts.
- **Knowledge could be duplicated without bound.** Imported file names were derived from a
  per-process hash seed, so every launch re-imported every source file under a new name.
  Names are now stable. One-time upgrade note: because the old names were unstable, files
  imported by a collector or folder sync before this release are copied once more under
  their new stable name. Delete the older duplicates once, and it stays stable afterwards.
- **Deleted content stayed searchable.** Deleting a task, note, project, or reminder removed
  the row but left its embeddings behind, so AI retrieval kept surfacing deleted content.
  Deletions now cascade through the vector index (including subtasks and project contents).
- **Auto-archive never ran.** The completed-task query compared against `"done"` while the
  stored value is `"Done"`, so the Settings toggle and day threshold had no effect. Note
  that with this fixed, completed tasks older than your threshold will begin archiving.

### Crash fixes

- Opening a conversation with malformed branch data, reading knowledge rows with empty
  columns, subprocess launch failures, negative-length string slices, a data race on the
  search index, and a main-thread deadlock in response streaming.

### MCP & CLI

- **Subtasks are now available to agents.** `workspace_task` gained `parent` on create and
  update, `parent` / `topLevelOnly` filters on list, and a `subtasks` array on get.
  Reparenting rejects cycles and self-parenting; deletes cascade. Previously subtasks
  existed only in the app UI and were invisible to Claude Code, Cursor, and other agents.
- **Tool contracts tightened.** Unknown update fields, out-of-enum `status`/`priority`,
  unresolvable project references, and invalid search types now fail with actionable
  messages instead of silently reporting success or returning every row in the workspace.
- **Retrieval no longer floods agent context.** `smart_query` full mode, session recall,
  project knowledge loads, and `knowledge_search` are capped and return relevance-windowed
  snippets with a pointer to the full content on disk.
- Numeric arguments are validated and clamped; `--help` and error messages now match the
  real command and tool set.
- Skills document the project → task → subtask ledger.

### App polish

- Fixed unclickable rule enable/disable toggles, palette navigation landing on the wrong
  tab, archived projects showing an empty pane, a blank terminal pane with no recovery,
  and dead Register/Install/Export buttons that silently no-opped without their prerequisite.
- Failed saves of knowledge entries, skills, rules, and agents now surface an error instead
  of silently discarding your edits and redisplaying the old content.
- Deleting a conversation now asks for confirmation.
- Empty, loading, and no-results states are now distinguishable across knowledge, search,
  graph, and handoff views; whitespace-only input is rejected on entry forms.

### Install

**Homebrew (recommended):**
```bash
brew tap getlost01/deepthink
brew update
brew upgrade --cask deepthink
```

**Manual:**
Download `DeepThink-1.0.3.zip`, unzip, drag to `/Applications`, then:
```bash
xattr -rd com.apple.quarantine /Applications/DeepThink.app
```
